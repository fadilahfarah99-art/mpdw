Double Moving Average (DMA)

DMA lebih cocok untuk data berpola tren. Karena dugaan awal kita adalah data ini stasioner (bukan tren), kita tetap coba DMA sebagai pembanding.

dma <- SMA(data.sma, n = 4)
At <- 2*data.sma - dma
Bt <- 2/(4-1)*(data.sma - dma)
data.dma <- At + Bt
data.ramal2 <- c(NA, data.dma)

t <- 1:n_test
f <- c()
for (i in t) {
  f[i] <- At[length(At)] + Bt[length(Bt)]*(i)
}

data.gab2 <- cbind(
  aktual     = c(farah.ts),
  pemulusan1 = c(data.sma, rep(NA, n_test)),
  pemulusan2 = c(dma, rep(NA, n_test)),
  At         = c(At, rep(NA, n_test)),
  Bt         = c(Bt, rep(NA, n_test)),
  ramalan    = c(data.ramal2, f[-1])
)

Double Exponential Smoothing (DES)

DES cocok untuk data berpola tren, menggunakan dua parameter: alpha (level) dan beta (tren).

des.1 <- HoltWinters(train.ts, gamma = FALSE, beta = 0.2, alpha = 0.2)
des.2 <- HoltWinters(train.ts, gamma = FALSE, beta = 0.3, alpha = 0.6)
des.opt <- HoltWinters(train.ts, gamma = FALSE)

Kesimpulan

Berdasarkan hasil eksplorasi awal, plot data menunjukkan pola stasioner/konstan (berfluktuasi di sekitar rata-rata, tanpa tren jangka panjang yang jelas). Hal ini konsisten dengan hasil perbandingan metode:

  • DMA menghasilkan error (MSE/MAPE) yang paling besar, karena metode ini dirancang untuk data bertren – memaksakan estimasi tren pada data yang sebenarnya tidak trending justru menambah kesalahan.
  • SMA memberikan hasil lebih baik daripada DMA, sesuai dugaan bahwa data ini lebih cocok didekati dengan metode untuk data stasioner.
  • SES dan DES dengan parameter optimal menghasilkan akurasi terbaik (MAPE data uji terkecil). Menariknya, parameter beta pada DES optimal cenderung mendekati nol, yang berarti model DES “menyusut” menjadi mirip SES – ini semakin menguatkan bahwa data tidak memiliki komponen tren yang signifikan.

Metode terbaik: Single Exponential Smoothing (SES) dengan alpha optimal, karena menghasilkan nilai MAPE data uji paling kecil di antara seluruh metode yang dicoba, sekaligus merupakan metode yang paling sesuai secara konseptual dengan pola data yang stasioner.
